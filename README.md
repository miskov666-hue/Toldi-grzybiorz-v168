# TOŁDI GRZYBIORZ — V168

- Nowa mechanika walki z Belzebubem: na czas walki zwykłe grzyby znikają, a na arenie pojawia się 6 Borowików Szatańskich.
- Zebranie Borowika daje czerwoną aurę i 5 strzałów grzybowych. Każde trafienie odbiera Belzebubowi 30 HP; po piątym strzale aura gaśnie.
- Borowiki są rozrzucone po mapie i nie pojawiają się pod osłonami. Nowe obiekty znikają po zakończeniu walki.
- Zachowano dotychczasowe mechaniki gry, w tym poprawkę ekranu śmierci UFO z V166.

Uruchom grę przez `index.html` lub opublikuj pliki w GitHub Pages.

- Po pokonaniu Belzebuba wyświetla się nowe prawdziwe zakończenie: pionowy komiks przez 30 sekund, z przyciskiem POMIŃ; po zakończeniu gra wraca do menu głównego.
- Komiks dodany do debugowania → lista komiksów.
